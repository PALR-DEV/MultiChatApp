# MultiChat 🚀

[![React](https://img.shields.io/badge/React-19.0.0-blue.svg)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-6.1.0-646CFF.svg)](https://vitejs.dev/)

[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4.0.7-38B2AC.svg)](https://tailwindcss.com/)

A modern, real-time chat application built with React and powered by Supabase, featuring a sleek user interface and robust authentication system.

## ✨ Features

- 🔐 Secure Authentication System
  - Email/Password Login
  - Google OAuth Integration
  - Modern and Responsive Login Interface
- 🎨 Sleek UI Design with TailwindCSS
- ⚡ Lightning Fast Development with Vite
- 🔄 Real-time Updates

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/multichat.git
cd multichat
```

2. Install dependencies
```bash
yarn install
# or
npm install
```

3. Start the development server
```bash
yarn dev
# or
npm run dev
```

## 🛠️ Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Styling**: TailwindCSS
- **Backend/Auth**: Supabase
- **Development Tools**:
  - ESLint
  - SWC (Fast Refresh)
